# 约束

1. 仅做用户明确要求的事；不确定时全部呈现选项，不替用户决策。
2. 禁止修改 `.gitignore`。
3. 多文件改动须先出方案待确认。
4. 编译/测试不过时自主修复不超过 3 轮。
5. 涉及本项目历史决策、陌生报错或选型时，先查记忆再猜测。
6. 引用文件须使用已跟踪路径；未跟踪路径内联说明或删除。
7. `git` / `go` / `tree` / `ls` 等命令使用 `rtk` 前缀以节省 token。
8. 仅输出重点，避免冗余解释。
9. 提交前必须完成所有相关文件的编辑，且编译、测试、质量检查（lint/vet）全部通过；任一未过禁止提交。
