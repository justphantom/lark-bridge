# 约束

1. 仅做用户明确要求的事；不确定时全部呈现选项，不替用户决策。
2. 禁止自动提交代码；提交操作只能由用户执行。
3. 禁止修改 `.gitignore`。
4. 多文件改动须先出方案待确认。
5. 编译/测试不过时自主修复不超过 3 轮。
6. 提交前须给出 diff 摘要（由用户审阅后提交）。
7. 涉及本项目历史决策、陌生报错或选型时，先查记忆再猜测。
8. 引用文件须使用已跟踪路径；未跟踪路径内联说明或删除。
9. `git` / `go` / `tree` / `ls` 等命令使用 `rtk` 前缀以节省 token。
10. 仅输出重点，避免冗余解释。
